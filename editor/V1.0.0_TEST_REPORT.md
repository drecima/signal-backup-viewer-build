## v1.0.0 candidate

The new `create-message` operation constructs:

- incoming direct and group text messages;
- outgoing text messages;
- Note to Self text messages;
- text messages with one copied or newly encrypted attachment;
- explicitly positioned historical messages.

Tests cover invalid Self/incoming combinations, invalid Note to Self
destinations, timestamp collisions, missing historical placement, successful
in-place attachment creation, and injected-failure rollback.

Every successful output passes the pinned official validator, protobuf
normalization, fresh archive encryption/HMAC, independent encrypted reopen,
reference checks, and applicable attachment cryptographic/manifest checks.
